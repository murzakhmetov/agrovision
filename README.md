# AgroVision AI - Бортовой Компьютер Опрыскивателя

Локальная веб-система компьютерного зрения для ПК и терминала самоходного опрыскивателя. Разработана для работы в полевых условиях без интернета (100% OFFLINE) с возможностью переключения в ONLINE режим.

## Функционал системы

- Бортовой терминал опрыскивателя для работы на скорости 18-20 км/ч в реальном времени.
- Точечное управление 8 независимыми секциями штанги шириной 24 метра через PWM.
- Классификация сорняков по регламенту агрономической службы: Класс A (двудольные) и Класс B (злаковые), малолетние и многолетние.
- Логика принятия решений по экономическому порогу вредоносности на 1 м2.
- Определение фаз развития сорняков и автоматический расчет корректировки дозировки гербицидов.
- Студия CV-анализа снимков поля с детекцией через локальные нейросети YOLO.
- Интерактивная карта полей с расчетом площади и контуров обработки.
- Чат-консультант агронома с автономной локальной базой знаний и онлайн-режимом.
- Переключатель режимов работы: OFFLINE / ONLINE.
- Многоязычный интерфейс: Русский, English, Казахский.

## Системные требования

- Python 3.10 или новее
- Git
- Веб-браузер: Chrome, Firefox, Edge, Safari
- Операционная система: Windows 10/11, Linux (Ubuntu, Debian, Fedora и др.), macOS

## Быстрый запуск с нуля

### 1. Linux (Ubuntu, Debian, Fedora, Arch)

1. Откройте терминал и установите необходимые системные пакеты (если они еще не установлены):
```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv git
```

2. Склонируйте репозиторий и перейдите в папку проекта:
```bash
git clone https://github.com/murzakhmetov/agrovision.git
cd agrovision
```

3. Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
```

4. Установите зависимости:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

5. Запустите сервер:
```bash
chmod +x start_pc_system.sh
./start_pc_system.sh
```
Или напрямую командой:
```bash
python3 -m uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

6. Откройте веб-интерфейс в браузере:
```
http://localhost:8000
```

### 2. Windows (PowerShell / Командная строка CMD)

1. Убедитесь, что установлены Python (версия 3.10+) и Git:
- Скачать Python: https://www.python.org/downloads/ (обязательно отметьте галочку "Add Python to PATH" при установке).
- Скачать Git: https://git-scm.com/download/win

2. Откройте PowerShell или CMD, склонируйте репозиторий и перейдите в папку:
```powershell
git clone https://github.com/murzakhmetov/agrovision.git
cd agrovision
```

3. Создайте виртуальное окружение:
```powershell
python -m venv venv
```

4. Активируйте виртуальное окружение:
В PowerShell:
```powershell
.\venv\Scripts\Activate.ps1
```
Если PowerShell блокирует скрипты, выполните:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```
В классической командной строке (CMD):
```cmd
venv\Scripts\activate.bat
```

5. Установите зависимости проекта:
```powershell
pip install --upgrade pip
pip install -r requirements.txt
```

6. Запустите сервер системы:
```powershell
python -m uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

7. Откройте веб-интерфейс в браузере:
```
http://localhost:8000
```

## Архитектура проекта

- `backend/server.py` - FastAPI бэкенд, REST API и раздача статики интерфейса.
- `backend/cv_engine.py` - Движок компьютерного зрения (YOLO инференс, классификация сорняков, расчет порогов вредоносности).
- `backend/offline_kb.py` - Автономная локальная база агрономических знаний и регламентов.
- `ml_models/` - Локальные веса обученных нейросетевых моделей детекции сорняков и культур.
- `web_app/index.html` - Основная разметка веб-интерфейса ПК-системы.
- `web_app/css/style.css` - Стили интерфейса бортового терминала.
- `web_app/js/app.js` - Управление состоянием приложения, навигация, переключение языков и режимов.
- `web_app/js/cv_player.js` - Модуль видеопотока бортового монитора и управления секциями штанги.
- `web_app/js/analysis.js` - Модуль инспекции фотоснимков и вывода рекомендаций.
- `web_app/js/fields_map.js` - Модуль векторной карты полей и контуров обработки.
- `web_app/js/chat.js` - Модуль диалога с консультантом агронома.
- `web_app/js/translations.js` - Локализация интерфейса на трех языках.
- `start_pc_system.sh` - Скрипт быстрого запуска для Unix-систем.
- `requirements.txt` - Список зависимостей Python.

## Основные разделы интерфейса

1. Дашборд - Сводные показатели экономии СЗР, обработанная площадь, статус форсунок и текущая погода.
2. Бортовой Мониторинг - Онлайн/оффлайн видеомонитор для опрыскивателя на скорости 18-20 км/ч с визуализацией 8 секций штанги.
3. Инспекция Снимков - Загрузка фотографий поля, инференс нейросетей, классификация сорняков (Класс A / B) и расчет нормы внесения.
4. Поля и Участки - Карта полей с отображением статуса засоренности и контуров обработки.
5. Агро-Чат - Экспертные рекомендации по препаратам и технологиям защиты растений.
6. Регламент - Агрономический справочник порогов вредоносности и фаз развития.
