# AgroVision AI - Бортовой Компьютер Опрыскивателя («Олжа Агро»)

Локальная веб-система компьютерного зрения для ПК и терминала самоходного опрыскивателя.
Разработана строго по регламенту ментора агрономической службы «Олжа Агро».

## 1. Функционал системы
- Бортовой терминал опрыскивателя для работы на скорости 18-20 км/ч (100% OFFLINE).
- Точечное управление 8 независимыми секциями штанги (24 метра) через PWM.
- Классификация сорняков: Класс A (двудольные) и Класс B (злаковые), малолетние и многолетние.
- Логика принятия решений по экономическому порогу вредоносности на 1 м2.
- Анализ фаз развития сорняков и автоматическая корректировка дозировки.
- Студия инспекции фото с локальным инференсом YOLO.



## 2. Запуск системы
Запуск через bash-скрипт:
./start_pc_system.sh

Или напрямую через uvicorn:
python3 -m uvicorn backend.server:app --host 0.0.0.0 --port 8000

Веб-интерфейс доступен по адресу:
http://localhost:8000
