# AgroVision AI - Бортовой Компьютер Опрыскивателя

Локальная веб-система компьютерного зрения для ПК и терминала самоходного опрыскивателя. Разработана для работы в полевых условиях без интернета (100% OFFLINE) с возможностью переключения в ONLINE режим с интеграцией Google Gemini AI Cloud.

## Быстрый запуск в 1 клик (без терминала)

### Для Windows:
Просто дважды нажмите левой кнопкой мыши по файлу:
- `AgroVision.exe` (или `AgroVision_Setup_and_Run.bat`)

Файл автоматически:
1. Проверит наличие Python в системе (если отсутствует - откроет страницу официальной загрузки).
2. Создаст изолированное виртуальное окружение.
3. Установит все необходимые библиотеки из requirements.txt.
4. Запустит локальный сервер AgroVision AI.
5. Автоматически откроет веб-интерфейс в вашем браузере по адресу http://localhost:8000.

### Для Linux / macOS:
Выполните запуск скрипта:
```bash
./start_pc_system.sh
```
Скрипт автоматически создаст окружение, установит библиотеки, запустит сервер и откроет браузер.

## Функционал системы

- Бортовой терминал опрыскивателя для работы на скорости 18-20 км/ч в реальном времени.
- Точечное управление 8 независимыми секциями штанги шириной 24 метра через PWM.
- Классификация сорняков по регламенту агрономической службы: Класс A (двудольные) и Класс B (злаковые), малолетние и многолетние.
- Логика принятия решений по экономическому порогу вредоносности на 1 м2.
- Определение фаз развития сорняков и автоматический расчет корректировки дозировки гербицидов.
- Студия CV-анализа снимков поля с детекцией через локальные нейросети YOLO.
- Интерактивная карта полей с расчетом площади и контуров обработки.
- Чат-консультант агронома с поддержкой двух режимов:
  - OFFLINE: автономная локальная база знаний регламентов Олжа Агро.
  - ONLINE: облачная модель Google Gemini AI (gemini-3.1-flash-lite) с предустановленным ключом API.
- Переключатель режимов работы: OFFLINE / ONLINE.
- Многоязычный интерфейс: Русский, English, Казахский.

## Системные требования

- Git
- Веб-браузер: Chrome, Firefox, Edge, Safari

## Ручная пошаговая установка с нуля

### 1. Windows (PowerShell / Командная строка CMD)

1. Убедитесь, что установлены Python (3.10+) и Git:
- Python: https://www.python.org/downloads/ (отметьте галочку "Add Python to PATH").
- Git: https://git-scm.com/download/win

2. Склонируйте репозиторий:
```powershell
git clone https://github.com/murzakhmetov/agrovision.git
cd agrovision
```

3. Запустите готовый исполняемый файл:
```powershell
.\AgroVision.exe
```
Или выполните команды вручную:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt
python -m uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

4. Откройте интерфейс в браузере:
```
http://localhost:8000
```

---

### 2. Linux (Ubuntu, Debian, Fedora, Arch)

1. Установите системные пакеты:
```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv git
```

2. Склонируйте репозиторий:
```bash
git clone https://github.com/murzakhmetov/agrovision.git
cd agrovision
```

3. Запустите автоматический скрипт:
```bash
chmod +x start_pc_system.sh
./start_pc_system.sh
```

4. Откройте интерфейс в браузере:
```
http://localhost:8000
```

---

### 3. macOS (Apple Silicon M1-M4 и Intel)

1. Установите Homebrew, Python 3 и Git:
```bash
brew install python git
```

2. Склонируйте репозиторий и перейдите в каталог:
```bash
git clone https://github.com/murzakhmetov/agrovision.git
cd agrovision
```

3. Создайте окружение и установите зависимости:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

4. Запустите сервер:
```bash
python3 -m uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

5. Откройте интерфейс в браузере:
```
http://localhost:8000
```

## Архитектура проекта

- `AgroVision.exe` - Исполняемый файл быстрого запуска для Windows в один клик.
- `AgroVision_Setup_and_Run.bat` - Скрипт автоматической установки и запуска для Windows.
- `start_pc_system.sh` - Скрипт автоматической установки и запуска для Linux и macOS.
- `requirements.txt` - Список Python-зависимостей системы.
- `backend/server.py` - FastAPI сервер, REST API, обработка видеопотока и Gemini AI Cloud.
- `backend/cv_engine.py` - Движок компьютерного зрения (инференс YOLO, классификация сорняков, пороги вредоносности).
- `backend/offline_kb.py` - Локальная база агрономических знаний и регламентов.
- `ml_models/` - Веса предобученных моделей детекции сорняков и культур.
- `web_app/index.html` - Веб-интерфейс ПК-системы.
- `web_app/css/style.css` - Стили интерфейса бортового терминала.
- `web_app/js/app.js` - Логика приложения, навигация, переключение языков и онлайн/оффлайн режимов.
- `web_app/js/cv_player.js` - Видеомониторинг опрыскивателя и визуализация 8 секций штанги.
- `web_app/js/analysis.js` - Модуль фотоинспекции и расчета регламентных норм СЗР.
- `web_app/js/fields_map.js` - Векторная карта полей и контуров обработки.
- `web_app/js/chat.js` - Модуль диалога с консультантом агронома.
- `web_app/js/translations.js` - Локализация интерфейса на трех языках.

## Основные разделы интерфейса

1. Дашборд - Сводная аналитика экономии СЗР, обработанная площадь, статус форсунок и погода.
2. Бортовой Мониторинг - Онлайн/оффлайн терминал штанги на скорости 18-20 км/ч с отображением 8 секций распыла.
3. Инспекция Снимков - Локальная детекция сорняков, распределение по Классам A и B и расчет дозировок.
4. Поля и Участки - Карта полей с мониторингом засоренности.
5. Агро-Чат - Консультации агронома (автономный режим или Gemini 3.1 Flash Lite).
6. Регламент - Официальный справочник агрономической службы по экономическим порогам вредоносности.
